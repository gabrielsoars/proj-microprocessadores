# proj-microprocessadores
Projeto final de microprocessadores.

# Funções
- 00xx: Acende o xx-ésimo led vermelho;
- 01xx: Apaga o xx-ésimo led vermelho;
- 10: Lê as chaves, calcula o número triangular e exibe no display de 7 segmentos;
- 20: Mostra a frase "OI 2026" no display de 7 segmentos com uma rotação em intervalos de 200ms;
- 21: Cancela a rotação da palavra.
